# Tempo

Личный планер. Один сайт: на компьютере это обычная страница, на iPhone — приложение на экране «Домой».

Файлы: `index.html` (всё приложение), `manifest.webmanifest`, `sw.js` (работа без интернета), `icons/` (иконки).
Личных данных в репозитории нет: задачи хранятся в браузере и, если включить синхронизацию, в вашем секретном Gist.
